🔑 Vocabulario básico de la automatización

Sensor: dispositivo que detecta una variable física (temperatura, distancia, luz, humedad) y la convierte en una señal eléctrica.

Actuador: elemento que ejecuta una acción física a partir de una señal de control (motor, servomotor, relevador, LED).

Controlador: el "cerebro" del sistema (en este caso Arduino) que lee sensores, toma decisiones según una lógica programada y activa actuadores.

Lazo de control: el ciclo continuo de sensar → procesar → actuar que mantiene un proceso dentro de los parámetros deseados.

Retroalimentación (feedback): cuando el sistema usa la salida de un proceso como información para ajustar su propio comportamiento.
